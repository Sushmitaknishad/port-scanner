# Port Scanner

A Python-based network security tool that scans TCP ports on a target host and identifies open ports.

## Features

- Scans specified TCP ports
- Identifies open ports
- Uses socket programming
- Handles network exceptions
- Uses TCP/IP networking concepts

## Technologies

- Python
- Socket Programming
- TCP/IP
- Networking
- Exception Handling

## How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Run:

```bash
python port_scanner.py
